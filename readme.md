# Natours Application

Node.js Backend Development Project (Natours)

• Built a full-stack tour booking web application using Node.js, Express.js, MongoDB, and Mongoose.
• Designed and developed RESTful APIs with CRUD operations for tours, users, reviews, and bookings.
• Implemented authentication and authorization using JWT, cookies, and role-based access control.
• Integrated Stripe Checkout payment system with secure webhook handling for online booking payments.
• Applied MongoDB aggregation pipelines for analytics such as average ratings and tour statistics.
• Implemented image upload and processing using Multer and Sharp.
• Developed secure middleware for error handling, data sanitization, and route protection.
• Used MVC architecture to organize scalable backend code structure.
• Implemented advanced Express features including middleware chaining, routing, and custom error handling.
• Worked with asynchronous JavaScript concepts including Promises, async/await, and event-driven programming.
• Connected and managed MongoDB database using Mongoose schemas, models, middleware, and validation.
• Deployed and configured production-ready backend environment variables and server settings.
• Used Git and GitHub for version control and project management.
